Fitur Aplikasi

Beberapa fitur yang terdapat dalam aplikasi ini:

1. Login dengan email dan password.
2. Validasi jika email atau password belum diisi atau salah.
3. Menampilkan halaman profil.
4. Edit informasi profil.
5. Halaman About Me.
6. Drawer untuk navigasi menu.
7. Dark Mode dan Light Mode.

Cara Menjalankan Aplikasi

1. Clone repository GitHub:
   
   git clone https://github.com/dynda21/soal2-profil-app.git

2. Masuk ke folder project:
   
   cd soal2-profil-app

3. Install dependencies:
   
   flutter pub get

4. Jalankan aplikasi:
   
   flutter run

Build APK

Untuk membuat file APK, jalankan perintah:

flutter build apk --release

File APK dapat ditemukan di:

build/app/outputs/flutter-apk/app-release.apk
